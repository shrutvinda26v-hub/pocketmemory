# BADDIE

**One woman. Many moods. One BADDIE.**

A cinematic, scroll-driven lipstick brand world — Indian maximalism × fashion illustration × Bollywood poster energy. Not a conventional cosmetics storefront.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- GSAP ScrollTrigger + Lenis for fashion-film scrolling
- Custom 3D CSS lipsticks, pin-and-scrub character scenes, shade universe + baddie quiz
