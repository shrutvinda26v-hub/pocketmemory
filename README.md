# Pocket Memory

A personal wardrobe and outfit journal. Track the clothes you own, build outfits, and remember what you wore.

## Features

- **Today** — suggested outfit, most-worn pieces, and recent wear history
- **Closet** — add, search, and filter wardrobe pieces by category
- **Outfits** — compose looks from your closet and log them as worn
- **Memory** — a dated journal of what you actually wore

Data is stored locally in your browser (`localStorage`).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
