# Memento Mori

Dark surreal poster still: a pair of hands releases glossy toy eyeballs from a skull. The eyes drop on novelty-toy metal springs. No gore — a mechanical jack-in-the-box beat.

## Frames

- `public/memento-mori-original.png` — eyes held in the sockets
- `public/memento-mori-springs.png` — eyes already sprung
- `public/memento-mori-hands-release-springs.png` — hands just letting go; eyes falling on springs
