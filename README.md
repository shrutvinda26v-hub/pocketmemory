# Fantasy Storybook

A premium cinematic interactive storybook. Click a page to turn it — each page is a different illustrated world.

## Worlds

1. Dragon Kingdom
2. Enchanted Forest
3. Floating Castle
4. Underwater Kingdom
5. Galaxy
6. Secret Garden

## Develop

```bash
npm install
npm run dev
```

Open the local URL, then click the right page (or drag the bottom-right corner) to turn forward. Click the left page to turn back. Arrow keys also work.
